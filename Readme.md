# Express.js Learning Repository

## 📌 Overview
This repository contains Express.js practice code and mini projects created during the learning period. It focuses on understanding backend development concepts such as routing, middleware, RESTful APIs, and server-side logic using Express.js.

## 🎯 Purpose
- Learn and practice Express.js fundamentals  
- Build backend APIs and server-side logic  
- Understand routing and middleware concepts  
- Use as a reference for backend development  

## 🧩 Contents
- Basic Express server setup  
- Routing and controllers  
- Middleware usage  
- REST API examples  
- Practice and experimental code  

## 🛠️ Tech Stack

- Express.js  
- JavaScript
